3. Assign

Use:

Rider      = 6a914701c4d362fbbda4c494
Dispatcher = 6a91da9a58d0259278f29780

Invoke-RestMethod `
  -Uri "http://localhost:5000/api/deliveries/6a95a78af6e1971f3ee32703/assign" `
  -Method PATCH `
  -ContentType "application/json" `
  -Body '{
    "riderId": "6a914701c4d362fbbda4c494",
    "dispatcherId": "6a91da9a58d0259278f29780"
  }'

Expected:

and:

4. Pickup
Invoke-RestMethod `
  -Uri "http://localhost:5000/api/deliveries/6a95a78af6e1971f3ee32703/status" `
  -Method PATCH `
  -ContentType "application/json" `
  -Body '{
    "status": "PICKED_UP",
    "riderId": "6a914701c4d362fbbda4c494"
  }'
Expected:

Delivery status updated successfully

and:

DELIVERY STATUS UPDATED EVENT
Status: PICKED_UP

testSocket response
***
=== DELIVERY STATUS UPDATED EVENT ===
Order Reference: FINAL-TEST-001
Status: PICKED_UP
Assigned Rider: 6a914701c4d362fbbda4c494
=====================================
***

5. Verify and deliver
Replace YOUR_FINAL_CODE with the code generated for FINAL-TEST-001.
Invoke-RestMethod `
  -Uri "http://localhost:5000/api/deliveries/6a95a78af6e1971f3ee32703/verify" `
  -Method POST `
  -ContentType "application/json" `
  -Body '{
    "verificationCode": "06E96143",
    "riderId": "6a914701c4d362fbbda4c494"
  }'

Expected:

Delivery verified and marked as delivered

and Socket.io:

DELIVERY DELIVERED EVENT
Status: DELIVERED
Verified: true

***
=== DELIVERY DELIVERED EVENT ===
Order Reference: FINAL-TEST-001
Status: DELIVERED
Verified: true
===============================
***
